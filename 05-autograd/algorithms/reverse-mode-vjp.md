# 反向自动微分：从链式法则到 VJP — 算法与不变量

## 梯度不是重新运行 N 次
设一个标量损失依赖 n 个参数。数值差分逐个扰动参数；符号微分构造导数表达式；自动微分则在实际执行的基本操作上应用局部导数。反向模式从输出开始传播余切，不需要显式构造完整雅可比矩阵。对一个标量输出，通常只需一轮反向传播取得整个梯度。[AD-2]

## 同一个变量被使用两次
令 a=x²，b=3x，L=a+b。x=2 时，a=4，b=6，L=10。反向以 L 的余切 1 为起点：加法向 a、b 各传 1；平方路径给 x 贡献 4，乘法路径贡献 3。x 的总梯度是 7，不是 4 或 3。

## 从标量推广到向量
若 y=f(x)，x∈Rⁿ、y∈Rᵐ，雅可比 J 的形状为 m×n，种子 v 的形状为 m，返回的梯度形状为 n。本文采用列向量约定。g=JTv,gi=∑j=1mvj∂yj∂xi例如 f(x₁,x₂)=(x₁x₂,x₁+x₂)，x=(2,3)，v=(4,5)，两个输入分别收到 4×3+5=17、4×2+5=13。非标量输出需要传入形状匹配的 grad_outputs（这里是实数向量）；默认标量种子为 1。
