高阶自动微分：Hessian、HVP 与 create_graph

为什么不必构造 n×n Hessian 也能计算曲率方向？对梯度再次微分，比较 reverse-over-reverse 与 forward-over-reverse。

源码范围：PyTorch 2.10.0 · 449b17684101 · PyTorch 2.10 CPU 实数 C² 标量函数；二阶导数与 HVP；不涵盖非光滑、复数或全部 transform 兼容性。

梯度告诉方向，Hessian 告诉梯度如何变化

对于标量函数 f: Rⁿ→R，梯度是 n 维向量，Hessian 是 n×n 矩阵。显式存储稠密 Hessian 需要 O(n²) 个元素；若算法只需要曲率方向 Hv，可以直接对梯度函数做方向微分。Pearlmutter 1994 是历史研究入口，本篇未阅读全文，不借其声称任何实测加速。

两条 HVP 路径

对 C² 实数标量函数，H=J(∇f) 对称。forward-over-reverse 是先 reverse 得到梯度，再 forward 得到其方向导数；reverse-over-reverse 则以 v 为种子对梯度执行 VJP，所得 Hᵀv 与 Hv 相同。

Hv=J∇fv=∇(vT∇f)

例：f=x₁³+x₁x₂+x₂²。梯度为 (3x₁²+x₂, x₁+2x₂)，H=[[6x₁,1],[1,2]]。在 (2,3) 代入 v=(4,5) 得 (53,14)。[HVP-1]

create_graph 与 retain_graph 的区别

create_graph=True 允许将求导操作本身记录为可微计算；retain_graph 保留原反向所需保存值，单独设为 True 并不等于记录导数图。torch.func.hessian 的固定版本源码直接返回 jacfwd(jacrev(func,argnums),argnums)，算子不支持前向 AD 时可考虑 jacrev(jacrev(func))。[HVP-2]

HVP 的适用边界

HVP 不显式物化 H，但仍需计算图和中间量，不能据此承诺常数内存或固定加速比。非光滑点可能不存在经典 Hessian；变量相关的 v 需考虑额外导数项。实验比较两条路线，并用默认 create_graph=False 构造负例。[HVP-3]

可运行实验

Python 3.13.5、PyTorch 2.10.0+cpu，float64。以下脚本及输出已经实际执行。

import torch

x = torch.tensor([2., 3.], dtype=torch.float64, requires_grad=True)
v = torch.tensor([4., 5.], dtype=x.dtype)
def f(z):
    return z[0]**3 + z[0]*z[1] + z[1]**2
loss = f(x)
g = torch.autograd.grad(loss, x, create_graph=True)[0]
hv = torch.autograd.grad(g, x, v)[0]
H = torch.func.hessian(f)(x.detach())
_, hv2 = torch.func.jvp(torch.func.grad(f), (x.detach(),), (v,))
expected = torch.tensor([[12., 1.], [1., 2.]], dtype=x.dtype)
assert torch.equal(H, expected) and torch.equal(hv, H @ v)
assert torch.equal(hv2, hv)
print('gradient:', g.tolist(), 'Hessian:', H.tolist())
print('HVP reverse/reverse and forward/reverse:', hv.tolist(), hv2.tolist())
g0 = torch.autograd.grad(f(x), x)[0]
assert not g0.requires_grad
try:
    torch.autograd.grad(g0.sum(), x)
except RuntimeError:
    print('without create_graph: second derivative rejected')
else:
    raise AssertionError('expected missing graph error')

HVP reverse/reverse and forward/reverse: [53.0, 14.0] [53.0, 14.0]

HVP-1 For a twice continuously differentiable scalar f, H v is JVP of grad(f); reverse differentiation of grad(f) with seed v returns H^T v, equal by symmetry. 限制：Real C² scalar f, fixed seed independent of x. [baydin] [hessian]

HVP-2 torch.func.hessian returns jacfwd(jacrev(func)); autograd.grad(create_graph=True) constructs derivative graph, while retain_graph concerns freeing the original graph. 限制：Forward AD operator coverage may be incomplete. [grad] [hessian]

HVP-3 For f=x₁³+x₁x₂+x₂² at (2,3), grad=[15,8], H=[[12,1],[1,2]], and both HVP routes yield [53,14]; default create_graph=False rejects this second derivative. 限制：A polynomial CPU example only. [grad] [hessian] [jvp]
