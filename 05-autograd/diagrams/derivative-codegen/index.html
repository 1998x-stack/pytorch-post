PYTORCH INTERNALS · AUTOGRAD / 05

derivatives.yaml：从导数规则到自动生成反向算子

PyTorch 并不是运行时对任意 C++ kernel 做符号微分。以 mul.Tensor 为例，追踪 schema、导数规则、代码生成以及广播梯度归约。

源码范围：PyTorch 2.10.0 · 449b17684101 · PyTorch 2.10 eager CPU dense real mul.Tensor；静态代码生成阅读与运行时数值验证，不重新编译 PyTorch。

正向 kernel 为什么不需要包含完整反向逻辑？

ATen schema 描述 mul.Tensor 的输入输出；实际算子实现负责数值计算。Autograd 规则另行描述怎样从输出余切求输入余切。它不是对 C++ 源文件自动求导的万能程序，也不是每次调用都重新读取 YAML。

构建阶段：规则如何成为 C++ 代码

native_functions.yaml 定义算子 schema；derivatives.yaml 对同一签名给出导数规则。gen_autograd.py 读取两者及 tags，经 load_derivatives 形成 differentiability info，再驱动 VariableType 与 Functions 的生成。前者为适用算子生成 Autograd wrapper，创建 grad_fn、收集 next edges；后者生成反向 Node 的计算代码。[CG-1]

mul.Tensor 的 self 与 other 规则都调用 mul_tensor_backward；result 条目是前向模式公式，不能当作反向 VJP。生成器中 needs_input_grad 决定是否计算相应输入梯度。源码还存在 composite、手写及特定 dispatch 规则，本文不推广到所有算子。

广播乘法的 VJP

x=(2×1)、y=(1×3)、z=(2×3)，zᵢⱼ=xᵢyⱼ。给定输出余切 g，输入梯度分别沿广播维度求和。

gxi=∑jgijyj,gyj=∑igijxi

本例中 g=[[1,2,3],[4,5,6]]。x 方向为 [4+10+18,16+25+36]=[32,77]；y 方向为 [2+12,4+15,6+18]=[14,19,24]。

运行阶段：公式与形状校验分工

mul_tensor_backward 在实数情况下给出逐元素乘法结果（源码还处理共轭及 real-to-complex）。Engine 的 validate_outputs_impl 调用 InputMetadata::maybe_reduce，兼容的广播梯度经 reduce_grad 调用 sum_to 恢复输入形状；不是 YAML 公式单独处理所有广播。[CG-2]

原生实验中反向节点名为 MulBackward0，结果与手工公式一致并通过 gradcheck。该运行验证安装版本的数值行为，不代表重新运行代码生成器或编译了 C++。[CG-3]

可运行实验

Python 3.13.5、PyTorch 2.10.0+cpu，确定性 float64 输入。以下是实际执行的脚本及输出。

import torch

x = torch.tensor([[2.], [3.]], dtype=torch.float64, requires_grad=True)
y = torch.tensor([[4., 5., 6.]], dtype=torch.float64, requires_grad=True)
g = torch.tensor([[1., 2., 3.], [4., 5., 6.]], dtype=torch.float64)
z = x * y
expected_x = (g * y).sum(dim=1, keepdim=True)
expected_y = (g * x).sum(dim=0, keepdim=True)
gx, gy = torch.autograd.grad(z, (x, y), g)
assert torch.equal(gx, expected_x) and torch.equal(gy, expected_y)
assert gx.shape == x.shape and gy.shape == y.shape
print('node:', type(z.grad_fn).__name__)
print('broadcast VJP:', gx.tolist(), gy.tolist())
assert torch.autograd.gradcheck(lambda a, b: a*b, (x, y))
print('gradcheck: passed')

实际输出

node: MulBackward0
broadcast VJP: [[32.0], [77.0]] [[14.0, 19.0, 24.0]]
gradcheck: passed
