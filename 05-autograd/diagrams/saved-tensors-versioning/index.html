SavedVariable：保存值、版本计数与原地修改

为什么 detach() 之后修改张量仍可能让 backward 报错？理解保存的前向值、共享版本计数和反向资源生命周期。

源码范围：PyTorch 2.10.0 · 449b17684101 · PyTorch 2.10 eager CPU、普通 SavedVariable 无 hooks 路径；不覆盖 inference tensor、所有别名机制或 hooks

如果前向的 x 被覆盖

令 x=2，L=x*x，前向结果 4。局部导数需要前向时刻的 x，因此正确梯度为 4。如果在 backward 前把 x 改成 3，直接读取当前 x 会得到错误的 6。自动微分必须保护保存值的语义，而不是盲目使用最新数据。

版本计数检测冲突

SavedVariable 在构造时记录版本。对于普通无 hooks 的 unpack，保存版本必须等于当前版本。若不一致就报错，防止使用被原地修改的保存值。下图中的 0、1 是教学示意；实际起始版本取决于张量历史。[SV-1]

detach 与 clone 的区别

detach() 断开反向关联，但不保证独立存储；修改 detached 别名仍会影响原张量，并共享版本计数。detach().clone() 则创建独立副本。在示例中，修改别名后 backward 抛错，而修改克隆副本后仍得到梯度 4。不是所有原地操作都会报错：是否保存、是否需要旧值、别名及 grad 模式共同决定行为。

不要把 no_grad 当作版本检查的绕过方式，也不要用 .data 隐藏修改。对真正需要修改的训练参数，在一次 backward 完成后通过 optimizer 按常规步骤更新。

保存值的生命周期与 retain_graph

当 keep_graph_ 为 false，执行完反向函数后 Engine 调用 release_variables；SavedVariable::unpack 遇到未定义 data 且无 hooks 时检查重复 backward 错误。retain_graph=True 保留本次 backward 所需状态，但不是 create_graph=True：后者用于构建导数计算的图。[SV-2]

对于 x*x，第一次保留图，第二次默认释放，两个梯度累积到 8；第三次报错。对于不需要保存中间值的简单算子，重复 backward 可能不报相同错误。2017 论文 §3/§3.1 提供设计背景，2.10 源码才是本文实现判断的依据。[SV-3]

可运行实验

环境：PyTorch 2.10.0+cpu、Python 3.13.5；使用确定性 float64 输入，未使用 GPU。toy 是教学模型，native 是 PyTorch 对照。

import torch

def check_version(saved, current):
    if saved != current:
        raise ValueError('stale saved value')

check_version(0, 0)
try:
    check_version(0, 1)
except ValueError:
    print('toy: mismatch rejected')
else:
    raise AssertionError('expected mismatch')
x = torch.tensor(2., dtype=torch.float64, requires_grad=True)
y = x*x
alias = x.detach()
before = x._version
alias.add_(1)
assert x._version == before + 1
try:
    y.backward()
except RuntimeError as exc:
    assert 'modified by an inplace operation' in str(exc)
    print('native: version mismatch rejected')
else:
    raise AssertionError('expected version error')
x = torch.tensor(2., dtype=torch.float64, requires_grad=True)
y = x*x
x.detach().clone().add_(1)
y.backward()
assert x.grad.item() == 4
print('clone leaves gradient:', x.grad.item())
x = torch.tensor(2., dtype=torch.float64, requires_grad=True)
y = x*x
y.backward(retain_graph=True)
y.backward()
assert x.grad.item() == 8
try:
    y.backward()
except RuntimeError as exc:
    assert 'backward through the graph a second time' in str(exc)
    print('released saved values: repeat rejected')
else:
    raise AssertionError('expected release error')

实际输出

native: version mismatch rejected
clone leaves gradient: 4.0
released saved values: repeat rejected
