AOTAutograd：联合图、前反向分区与保存值

从动态 eager tape 到可交给编译器的 FX 图。观察 forward 的额外返回值如何成为 backward 的输入。

源码范围：PyTorch 2.10.0 · 449b17684101 · PyTorch 2.10 CPU aot_function 默认 partition_fn；真实捕获 FX 图并执行，不运行 Inductor 或 min-cut 性能实验。

为何捕获 forward 还不够？

Dynamo 捕获可编译的前向片段，但训练还需要反向。AOTAutograd 利用自动微分与 tracing 捕获联合前反向图，然后将其分割，交给后端。2024 ASPLOS 论文 §3.9 说明了 fake tensor、联合图、functionalization、decomposition 与分区的设计。现代 2.10 源码决定本文实际接口。[AOT-1]

联合图切开后的接口

设 L=sum(x·sin(x))，输入 x 为实数向量。反向给定标量种子 g，梯度为 g·(sin(x)+x·cos(x))。要执行 backward，可保存 x、sin(x)，也可考虑重算部分中间量。实际 default_partition 默认尽量保留原前后向放置，把反向所需保存值作为前向的额外输出。

min-cut rematerialization 是可选分区策略，论文说明用图割结合重计算优化存储；本次直接使用 aot_function 默认分区，不把实验说成运行了 min-cut。[AOT-2]

实际捕获的 FX 图

真实 forward FX 返回 (sum_1, primals_1, sin)，用户可见输出仍只是 loss；后两个值为反向接口需要的中间状态。backward 输入包含 primals_1、sin、tangents_1，展开种子，计算 sin 项与 x·cos(x) 项相加。下面的完整运行日志来自捕获回调。

这是 FX 表示与执行验证：compiler 回调返回 make_boxed_func(gm.forward)，没有生成优化后的 C++ 或 GPU kernel。[AOT-3]

与其他组件的边界

功能化旨在把 mutation 转换成可分析的函数式表达，别名及输入更新还需 wrapper 维持语义；decomposition 把高层算子映射到更基础算子。此例没有 mutation，不宣称验证别名或动态 shape。AOTAutograd 的捕获边界通常与前向编译片段关联；下一篇 Compiled Autograd 研究在 backward 时捕获更大运行时图。

可运行实验

Python 3.13.5、PyTorch 2.10.0+cpu、OMP_NUM_THREADS=1。以下脚本已实际执行，退出码 0。

import torch
from torch._functorch.aot_autograd import aot_function
from functorch.compile import make_boxed_func

seen = {}
def compiler(stage):
    def capture(gm, args):
        seen[stage] = gm.code
        print(stage, 'FX graph:')
        print(gm.code.strip())
        return make_boxed_func(gm.forward)
    return capture
def f(x):
    return (x.sin() * x).sum()
x = torch.tensor([0.2, 0.7], dtype=torch.float64, requires_grad=True)
eager = f(x)
g = torch.autograd.grad(eager, x)[0]
compiled = aot_function(f, fw_compiler=compiler('forward'), bw_compiler=compiler('backward'))
y = compiled(x)
g2 = torch.autograd.grad(y, x)[0]
assert torch.allclose(y, eager) and torch.allclose(g2, g)
assert set(seen) == {'forward', 'backward'}
print('forward/backward captured; eager gradient match:', torch.allclose(g2, g))

forward FX graph:
def forward(self, primals_1):
    sin = torch.ops.aten.sin.default(primals_1)
    mul = torch.ops.aten.mul.Tensor(sin, primals_1)
    sum_1 = torch.ops.aten.sum.default(mul);  mul = None
    return (sum_1, primals_1, sin)
backward FX graph:
def forward(self, primals_1, sin, tangents_1):
    expand = torch.ops.aten.expand.default(tangents_1, [2]);  tangents_1 = None
    mul_1 = torch.ops.aten.mul.Tensor(expand, sin);  sin = None
    mul_2 = torch.ops.aten.mul.Tensor(expand, primals_1);  expand = None
    cos = torch.ops.aten.cos.default(primals_1);  primals_1 = None
    mul_3 = torch.ops.aten.mul.Tensor(mul_2, cos);  mul_2 = cos = None
    add = torch.ops.aten.add.Tensor(mul_1, mul_3);  mul_1 = mul_3 = None
    return (add,)
